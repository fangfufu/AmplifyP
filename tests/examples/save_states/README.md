The original of the files in this folder:

- `amplify_4_all_primers.tsv` is from
  `Amplify4/Amplify4.app/Contents/Resources/Amplify Sample Primers.primers`
- `amplify_4_template.txt` is from
  `Amplify4/Amplify4.app/Contents/Resources/Amplify Sample Target.rtf`
- `amplify_4_full_example.yaml` was created by loading in
  `amplify_4_all_primers.tsv` and `amplify_4_template.txt` and saving the state.
- `simple.yaml` was created from Amplify 4's samples.
- `overlapping_primers.yaml` contains primers which are overlapping.
- `long_amplicons.yaml` contains a template and primer set that produce long
  amplicons with high raw $Q$ scores.
- `lots_of_amplicon.yaml` contains a template and primer set that produce many
  amplicons across a wide range of $Q$ scores.
